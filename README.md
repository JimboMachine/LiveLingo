# 即時翻譯（本地端）

在你自己的電腦上執行的翻譯小視窗。文字辨識、語音辨識和翻譯都在本機完成，不用帳號、不用 Token、沒有次數限制，聊天內容和聲音都不會傳到外面。

## 它能做什麼

1. **自動讀螢幕翻譯**：把螢幕上的聊天區框起來，對方傳來韓文，小視窗就會自動顯示繁體中文。
2. **打中文變韓文**：在小視窗下方輸入中文按 Enter，會翻成韓文並自動複製，到 Discord 按 Ctrl+V 貼上就能傳。韓文下面會附上唸法。
3. **複製就翻譯**：在任何地方選取外文按 Ctrl+C，小視窗會自動翻成繁體中文。
4. **聽對方說話**：把電腦正在播放的聲音（語音通話裡對方說的韓文）辨識成文字，翻成繁體中文顯示在小視窗。
5. **聽我說話**：你對麥克風說中文，就翻成韓文並附上唸法，照著唸就能說給對方聽。你說韓文，就翻成中文，可以確認自己說得對不對。

它只是「看螢幕畫面」、「讀剪貼簿」和「錄下電腦本來就在播放的聲音」，不會登入你的 Discord 帳號，也不會碰 Discord 或遊戲的程式本身。

## 電腦需求

- Windows 10 或 11（64 位元）
- 記憶體：只用文字翻譯 8 GB 以上；要用語音翻譯建議 16 GB（翻譯引擎約用 3.5 GB，語音辨識再加約 1.5 GB）
- 硬碟空間約 6 GB
- 安裝時需要網路，裝好之後離線也能用

## 安裝（只要做一次）

1. 把 `live-translator.zip` 解壓縮到一個好找的地方，例如 `D:\live-translator`。
2. 點兩下 `setup.bat`。
   - 如果跳出「Windows 已保護您的電腦」，按「其他資訊」再按「仍要執行」。
   - 電腦沒有 Python 的話，它會先問你要不要自動安裝 Python 3.12。
   - 接著會下載翻譯引擎和模型，總共約 4.2 GB，請等它跑完。中途斷線的話再點一次 `setup.bat`，會從中斷的地方繼續。
3. 看到「安裝完成」就可以關掉視窗。

**已經裝過前一版的話**：把新的 zip 解壓縮到同一個資料夾蓋過去，再點一次 `setup.bat`。已經下載過的模型不會重新下載，只會補上語音辨識需要的部分（約 1.6 GB）。

## 使用

點兩下 `start.bat`。會出現一個黑色視窗（會自己縮到工作列，**不要關掉它**，關掉就等於結束程式）和一個深色的翻譯小視窗。等狀態列顯示「已就緒」（大約半分鐘到一分鐘）就能用了。

### 讀螢幕翻譯

1. 打開 Discord 的聊天畫面，按小視窗上的 **框選聊天區**，用滑鼠把「訊息顯示的範圍」框起來。
2. 之後對方傳韓文，小視窗就會出現原文和中文翻譯。

- 只框訊息區就好，**不要把下面的輸入框框進去**，不然你正在打的字也會被拿去辨識。
- 翻譯小視窗盡量不要蓋住框起來的範圍，放在旁邊最保險。
- Discord 的聊天區要「看得到」才讀得到。視窗被縮小或被別的視窗完全蓋住時就讀不到。
- 玩遊戲時想同時看翻譯，遊戲請用「無邊框視窗」模式，小視窗才能疊在遊戲上面。
- 範圍會記住，下次開啟不用重框。Discord 視窗位置換了再重新框一次就好。

### 回覆對方（打字）

在小視窗最下面輸入中文，按 Enter。翻好的韓文會出現在小視窗裡（藍色字），同時已經複製好了，到 Discord 按 Ctrl+V 再送出。

### 語音翻譯

小視窗第二排有兩個開關，按一下變成藍色就是開啟，再按一下關閉。第一次開啟要等大約 10 秒載入語音辨識。

- **聽對方說話**：辨識電腦播放的聲音。對方講完一句話，大約 3 到 5 秒後會出現「［聽到］韓文原文」和中文翻譯。
- **聽我說話**：辨識你的麥克風。你說完一句中文，會出現韓文翻譯和唸法（例如 `唸法：nado joahae`），韓文也會自動複製。你說韓文的話，會顯示中文意思。

使用語音的注意事項：

- **請戴耳機**。用喇叭的話，麥克風會把對方的聲音也收進去，當成是你說的。
- **先按「裝置」選好要聽的裝置**：「聽對方說話」選你實際在聽 Discord 聲音的那個耳機或喇叭，「聽我說話」選你的麥克風。沒選的話會用 Windows 的預設裝置，有時候預設會是螢幕的喇叭（例如 `MSI G274QPF (NVIDIA High Definition Audio)`），那樣就聽不到對方。選過一次會記住，開啟語音後狀態列會顯示目前在聽哪個裝置。
- 「聽對方說話」會聽到電腦播放的所有聲音。同時開著影片、直播的話，裡面的韓文也會被翻譯。程式有先判斷「是不是人在說話」再辨識，但遊戲音效很吵時的效果我還沒辦法實測。
- 一句話說完要停頓一下（大約半秒）才會開始翻。一直講不停的話，每 12 秒會先切一段出來翻。
- 語音沒反應的話，點兩下 `check_audio.bat`，它會列出裝置並測試收音，把結果截圖給我。

## 專有名詞表（glossary.txt）

選手名、遊戲名、暱稱這類常被翻錯的詞，可以寫進 `glossary.txt`，一行一個：

```
쵸비 = Chovy
Chovy = 쵸비
```

用記事本改完存檔就生效，不用重開程式。裡面已經放了幾個例子。

## 可以調整的設定（config.json）

第一次關閉程式後會出現 `config.json`，用記事本就能改（改之前先把程式關掉）：

| 設定 | 預設 | 說明 |
| --- | --- | --- |
| `friend_lang` | `ko` | 對方的語言。可改成 `en`（英文）或 `ja`（日文，螢幕辨識目前只支援韓文和英文） |
| `also_english` | `false` | 改成 `true` 的話，螢幕上的英文訊息也會翻譯 |
| `tone` | `casual` | 翻成韓文時的語氣。`casual` 是朋友間的半語，`polite` 是有禮貌的 해요體 |
| `show_pronunciation` | `true` | 韓文下面要不要顯示唸法 |
| `copy_spoken` | `true` | 你用說的翻出來的韓文要不要自動複製 |
| `mic_langs` | `null` | 你會對麥克風說的語言。預設中文、韓文都可以；只說中文的話改成 `["zh"]` 會更準 |
| `listen_langs` | `null` | 對方說的語言。預設跟 `friend_lang` 一樣；韓文、英文都有的話改成 `["ko", "en"]` |
| `end_silence` | `0.6` | 停頓幾秒算一句話說完。常被切太碎可以改成 `0.9` |
| `speaker_device` / `mic_device` | `null` | 要聽的播放裝置和麥克風。直接按視窗上的「裝置」選就好，不用手動改 |
| `interval` | `0.7` | 每隔幾秒看一次螢幕。數字越小反應越快，但比較吃 CPU |
| `opacity` | `0.92` | 小視窗的透明度，0.3 到 1 |
| `threads` / `whisper_threads` | `0` / `4` | 翻譯引擎、語音辨識各用幾個 CPU 核心。玩遊戲會卡的話可以改小 |

## 測試狀況（老實說）

已經實際測過的部分（在 Linux 測試機上，用真的模型跑）：

- 讀螢幕：用你之前貼的 Discord 截圖當畫面，辨識韓文、判斷哪些是新訊息、翻成繁體中文、打中文翻成韓文並複製、複製就翻譯，全部正常。一則訊息從出現到翻好大約 3 到 5 秒。
- 語音：用真人朗讀的韓文、中文錄音「即時播放」給程式聽，切句、辨識、自動分辨中文或韓文、翻譯、顯示唸法、自動複製，全部正常。辨識一句約 1.6 秒，加上翻譯，說完後大約 3 到 5 秒出現結果（4 核心 CPU，不用顯示卡）。
- 模型下載和斷線續傳。
- 需要的元件在 Windows 的 Python 3.12、3.13、3.14 上都有現成的安裝檔。

還沒辦法測、要在你的電腦上跑過才知道的部分：

- `setup.bat`、`start.bat`、`check_audio.bat` 這幾個 Windows 批次檔。
- 在 Windows 上擷取螢幕，以及多螢幕、螢幕縮放（125%、150%）下的框選位置。
- **在 Windows 上收音（電腦播放的聲音和麥克風）**。這部分完全沒辦法在我這邊測，是最可能需要修的地方。
- 自動下載 Windows 版翻譯引擎這一步。
- 語音測試用的是清楚的朗讀錄音。實際語音通話有口語、背景音、多人同時說話，準確度會比測試時差。

所以第一次安裝如果卡住是正常的，把黑色視窗的內容截圖傳給我，我會修好。

## 常見問題

**翻譯有點慢，或玩遊戲時會卡？**
翻譯和語音辨識都是用 CPU 在算。可以把 `config.json` 的 `threads` 和 `whisper_threads` 改小（例如各 4 和 2），或是不需要時把語音開關關掉、按「暫停」。你的電腦如果有獨立顯示卡，可以改用顯示卡加速，跟我說顯示卡型號我再幫你設定。

**螢幕辨識有些字認錯？**
偶爾會把長得像的韓文字看錯（例如 쵸 看成 초），或漏掉空格。大部分情況翻譯引擎還是看得懂；專有名詞可以加進 `glossary.txt`。把 Discord 的字體放大一點（Ctrl 加 +）辨識會更準。

**語音辨識出現沒人說過的句子？**
語音辨識在只有音樂或雜音時偶爾會「幻聽」。常見的幾種已經過濾掉了，還有遇到的話把那句話貼給我，我加進過濾清單。

**唸法怎麼看？**
是韓文的羅馬拼音，照著英文字母的直覺唸就很接近，例如 `annyeonghaseyo`（안녕하세요）。`eo` 唸像「喔」，`eu` 唸像「呃」，`ae` 唸像「ㄝ」。

**BabelBot 的翻譯也被翻了一次？**
如果頻道裡還有 BabelBot，它貼出來的韓文也會被當成新訊息。用這個程式之後就可以不用 BabelBot 了。

**怎麼完全關掉？**
關掉翻譯小視窗，或關掉工作列上的黑色視窗。

**怎麼卸載？**
先把翻譯程式關掉，然後點兩下資料夾裡的 `uninstall.bat`，輸入 Y 確認。它會刪掉程式、下載的模型、專用環境和設定（約 5 GB），只刪這個程式自己的檔案，不會動到其他東西。重新跑過一次這版的 `setup.bat` 之後，也可以從 Windows 的「設定 → 應用程式 → 已安裝的應用程式」找到「即時翻譯 Live Translator」來卸載。當初如果有自動安裝 Python 3.12，那個要另外在同一個清單裡移除。這個卸載檔我還沒辦法在 Windows 上實測；萬一沒刪乾淨，直接把整個資料夾丟進資源回收筒也可以。
